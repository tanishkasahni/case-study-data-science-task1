# Case Studies in Data Science — Individual Task 1

Customer churn analysis for a Data Scientist role at Accenture Australia.

## Datasets
- Telco Customer Churn (Kaggle/IBM): https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- Online Retail II (UCI): https://archive.ics.uci.edu/dataset/502/online+retail+ii

Data files are not included — download from the links above into a `data/` folder.

## Models
Logistic regression and gradient boosting, fitted separately to each dataset.
Evaluated on precision, recall, F1, ROC-AUC and PR-AUC.

## Running
Requires pandas, scikit-learn, openpyxl. Open `Individual part 1.ipynb` and run cells in order.
